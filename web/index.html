Fake Drive Checker

Cheap "2 TB" flash drives and "20 TB" SSDs often hold only a few GB. Everything you save past the real size silently disappears. This test writes data to the whole drive and checks that it all comes back.

Runs entirely in your browser. Nothing is uploaded.

This browser can't run the test

The test needs to write files to a drive you pick, which only Chrome and Edge on a desktop or laptop can do (not Firefox, Safari or phones). Open this page in one of those, or use the desktop app.

You have a test waiting to be read back.

1 Pick the drive

  • Back up anything on the drive first. On a fake drive, the test can overwrite files that are already on it.
  • Plug it straight into the computer, not through a hub.
  • It takes a while: writing runs at the drive's speed (fakes often do 5–10 MB/s, about 30 min per 10 GB). Keep this tab open.

3 Eject and replug the drive

This empties the computer's memory of what was just written, so the next step reads from the drive itself. Skipping it can make a fake drive pass.

  1. Eject it safely: right-click the drive in File Explorer and choose Eject (on a Mac, drag it to the Trash).
  2. Unplug it and wait 5 seconds.
  3. Plug it back in.

How it works

    
The page fills the drive with 64 MB files of unique, checkable data. Every 4 KB piece is stamped with
      its own position. After the replug it reads everything back. Good drives return every byte. Fakes give
      themselves away: past the real capacity the data comes back as zeros or blanks, or the drive "wraps
      around" and quietly overwrites its own beginning. The stamps show which one happened and where it starts.

    
The page can't see the drive's hardware IDs or its claimed size, and it needs the replug step because
      browsers can't skip the file cache.

  


  

    
Desktop app (Windows)

    
The desktop version does more: it reads the drive's USB ID and flags known counterfeit chips, needs no
      replug (it reads straight from the device), and stops early when it detects a fake instead of filling a
      "20 TB" drive. It's a small Python app, source on
      GitHub: py -m fakecheck.
